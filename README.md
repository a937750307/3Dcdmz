# 3D场地模组

一个纯前端的 3D 活动场地效果图工具，用来快速搭建婚礼、发布会、年会、展览等场地方案。无需安装、无需联网、无需本地服务器，双击 `index.html` 即可在浏览器中打开使用。

## 主要功能

- **现成模板**：内置婚礼、新品发布会、艺术展览、企业年会四套模板，一键套用（默认发布会）。婚礼模板为华丽宴席式：红色 T 型舞台、台阶、红毯、甜品台、入口花艺拱门、中央大屏 + 左右小屏。
- **自定义空间**：可调整场地宽度、进深、层高与地面颜色；支持移除半透明空气墙、移除地面网格、一键全局去色（优先级最高，导出效果图同步生效）。
- **成套模组**：舞台 / T 台 / 台阶、LED 屏、喷绘背景、桁架（无灯 / 带灯 / 含屏 / 含喷绘）、桌椅组合、花艺、气球、拱门、灯具等，点击即添加到场景。
  - 座位分为「单桌单椅」「圆桌桌椅套装」「长桌桌椅套装」，圆桌/长桌支持 1–20 人规格。
  - 灯具分有柱 / 无柱，均为白天场景实体造型，不发光、不投射光束。
- **属性编辑**：选中模组后可调整尺寸、颜色、位置、H 高度、旋转、整体缩放等，每个数值项都提供滑条 + 可填写数字框。
- **图层管理**：支持锁定、多选（Ctrl / ⌘）、组合 / 解散、整体移动与旋转、折叠收起成员；锁定对象不可拾取、拖拽、删除或编辑。
- **视角与预览**：透视 / 俯视 / 正视切换；「预览」模式下拖拽只旋转镜头、不会移动物体，适合查看最终效果。
- **方案存取**：可保存到浏览器本地并读取，支持导出方案文件（JSON）与导入，另有「新建」清空场景。
- **效果图导出**：一键导出当前视角的 PNG 图片。

## 使用方法

1. 直接双击 `index.html` 用浏览器打开（推荐 Chrome / Edge）。
2. 左侧选择模板开始，或从模组库逐个添加；点击场景中的模组或左侧图层即可选中编辑。
3. 画布操作：拖拽模组移动、空白处拖拽旋转、滚轮缩放；`Delete` 删除选中模组。
4. 顶部可新建、读取、保存、导入 / 导出方案，以及导出效果图。

> 通过 URL 参数可指定初始模板和地面色，例如 `index.html?tpl=wedding&floor=%23d8d8d4`。

## 文件结构

```
.
├── index.html              # 页面结构
├── styles.css              # 界面样式
├── app.js                  # 全部逻辑：模组、模板、交互、存取
└── vendor/legacy/
    ├── three.min.js        # Three.js（传统脚本版）
    └── OrbitControls.js    # 轨道相机控制器
```

## 技术说明

- 使用 Three.js 传统脚本版本（非 ES Module），因此 `file://` 协议下可直接运行。
- 所有依赖均在本地 `vendor/` 目录，无外部网络请求。
- 保存的方案存放在浏览器 `localStorage`（键名 `venuekit.scene`）；导出的方案是标准 JSON 文件，可跨设备导入。
- 本站内容仅供学习和交流，非商业用途。
